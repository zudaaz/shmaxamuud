In this unit, you will learn the basics of web development. This unit places emphasis on web page structure using HTML and presentation using CSS.

  • Demonstrate HTML coding skills.
  • Use CSS to style web pages.

1.3 Web Development Layers

A website is a collection of related web pages hosted on a web server. Web pages can contain text, images, audio and videos.

A web page is created using three layers:

  1. Content Layer
  2. Presentation Layer
  3. Behaviour Layer

HTML creates structure, CSS controls design and JavaScript adds behavior.

What Is World Wide Web?

The World Wide Web (WWW) is a system used to exchange information through the Internet using hyperlinks and URLs.

Hyperlink

A hyperlink is a clickable text, image or button that connects users to another resource or webpage.

HTTP & HTTPS

HTTP stands for Hypertext Transfer Protocol.

HTTPS is the secure encrypted version of HTTP.

URL

URL stands for Uniform Resource Locator.

Example:

https://google.com

Web Browser

A web browser allows users to access websites on the Internet.

  • Google Chrome
  • Microsoft Edge
  • Mozilla Firefox
  • Safari

Web Server

A web server stores website files and delivers them to users through HTTP.
